# Fonts used by the diagram kit

Copied unchanged from `unity/Assets/MetaCodex/Fonts/`. The font files are not modified, so the licence name rules are met.

| File | Font | Use | Licence | Licence file |
|---|---|---|---|---|
| `Rajdhani-SemiBold.ttf` | Rajdhani SemiBold | titles, labels (capitals) | SIL Open Font License 1.1 | `Rajdhani-OFL.txt` |
| `Inter-Medium.ttf`, `Inter-SemiBold.ttf` | Inter Medium, SemiBold | body text, chips, pills | SIL Open Font License 1.1 | `Inter-OFL.txt` |
| `DejaVuSansMono.ttf` | DejaVu Sans Mono | code and paths | Bitstream Vera licence (free to use, copy, embed and redistribute; the licence text must stay with the fonts; a modified font must be renamed; the fonts may not be sold alone). DejaVu's own changes are public domain. | `DejaVu-LICENSE.txt` |

Notes:

- The OFL allows use, embedding and redistribution, also in rendered images. The PNGs in `docs/assets/diagrams/` only contain rendered glyphs.
- `DejaVu-LICENSE.txt` is the Debian copyright file of `fonts-dejavu-core`. The Bitstream Vera terms are in its first section. The GPL-2+ section in it covers only Debian's packaging files, not the font.
